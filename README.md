# Blog Portfolio

A simple personal portfolio and blog website where I can showcase my projects, skills, and share things I'm learning.

I built this project to improve my frontend development skills and get hands-on experience with authentication and managing a web application.

## Features

- Personal portfolio
- Projects showcase
- Blog section
- Contact section
- Firebase Authentication
- Responsive design
- Clean and modern UI

## Technologies

- HTML
- CSS
- JavaScript
- React.js
- Tailwind CSS
- Firebase
- Firebase Authentication

## What I Learned

While building this project, I learned and practiced:

- Building responsive user interfaces
- React components and state management
- Firebase integration
- Firebase Authentication
- Working with APIs
- Creating and managing blog content
- Deploying a web project
